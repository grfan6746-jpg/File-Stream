# 📺 Android TV Local Media Server (Termux Edition)

پروژه کامل، فوق‌العاده سبک و بهینه‌سازی شده برای اجرای لوکال مدیا سرور (Local Media Server) با **Python + Flask** بر روی محیط **Termux** در انواع تلویزیون‌های هوشمند **Android TV**.

این سرور فایلهای ویدیویی، موسیقی و تصاویر موجود در حافظه داخلی تلویزیون و فلش‌مموری‌ها یا هارد اکسترنال‌های متصل به USB را از طریق شبکه محلی (Wi-Fi یا کابل LAN) به گوشی، تبلت یا رایانه به اشتراک می‌گذارد و امکان **پخش مستقیم در اپلیکیشن محبوب VLC Media Player بدون نیاز به دانلود کامل فایل و بدون Transcoding (فشار صفر روی پردازنده تلویزیون)** را فراهم می‌کند.

## ۱. معرفی پروژه

بسیاری از تلویزیون‌های اندرویدی دارای سخت‌افزار متوسط یا ضعیف (۱ الی ۲ گیگابایت رم و پردازنده ۴ هسته‌ای ARM) هستند. راه‌اندازی سرورهایی مانند Plex یا Emby روی این تلویزیون‌ها به دلیل مصرف رم و پردازش ترنسکودینگ (Transcoding) باعث داغ شدن، کُند شدن و حتی کرش دستگاه می‌شود.

این پروژه اختصاصاً با این اصول ساخته شده است:
- **صفر درصد Transcoding:** فایل اصلی (MKV, MP4, AVI, FLAC و ...) بدون هیچ تغییری مستقیماً به کلاینت فرستاده می‌شود تا CPU تلویزیون استراحت کند.
- **پشتیبانی کامل از HTTP Range Request (RFC 7233):** امکان عقب/جلو بردن فیلم (Seek Forward/Backward)، مکث (Pause) و ادامه پخش (Resume) آنی در VLC بدون وقفه.
- **استریم جریانی تکه‌ای (Chunked Generator):** فایل‌های سنگین ۱۰ تا ۵۰ گیگابایتی 4K بدون بارگذاری در رم مستقیماً در قطعات ۱ مگابایتی از حافظه خوانده شده و ارسال می‌شوند. در نتیجه مصرف رم تلویزیون زیر ۴۰ مگابایت باقی می‌ماند!
- **عدم نیاز به روت (Root-Free):** با سازوکار استاندارد Storage Access Framework و پیوندهای Termux کار می‌کند.
- **رابط کاربری مناسب کنترل تلویزیون (Remote-Friendly):** ابعاد بزرگ دکمه‌ها، فونت خوانا، تم تاریک و پشتیبانی از D-Pad.

## ۲. پیش‌نیازها

- یک دستگاه تلویزیون یا تی‌وی‌باکس با سیستم‌عامل **Android TV (نسخه 7 به بالا)**.
- نرم‌افزار **Termux** نصب شده روی تلویزیون.
- گوشی اندروید یا تبلت دارای برنامه **VLC Media Player**.
- اتصال هر دو دستگاه به **یک مودم/روتر Wi-Fi یا کابل LAN مشترک**.

## ۳. نصب Termux روی Android TV

> ⚠️ **نکته بسیار مهم:** نسخه موجود در Google Play Store سال‌هاست آپدیت نشده و از کار افتاده است. **حتماً نسخه F-Droid یا GitHub را نصب کنید.**

1. اپلیکیشن **Downloader** را از گوگل‌پلی تلویزیون نصب کنید یا فایل APK ترموکس را روی فلش بریزید.
2. نسخه معماری `arm64-v8a` یا `armeabi-v7a` برنامه **Termux** را از آدرس رسمی F-Droid دانلود و روی تلویزیون نصب کنید:
   `https://f-droid.org/packages/com.termux/`
3. برنامه Termux را روی تلویزیون باز کنید. برای تایپ راحت‌تر می‌توانید از کیبورد بلوتوثی یا نرم‌افزارهای ریموت گوشی مانند **Android TV Remote** استفاده نمایید.

## ۶. اجرای termux-setup-storage

این دستور دسترسی ترموکس به حافظه داخلی تلویزیون و مسیرهای ذخیره‌سازی را فعال می‌کند:

```bash
termux-setup-storage
```

روی صفحه تلویزیون پیامی با مضمون **"Allow Termux to access photos, media and files"** ظاهر می‌شود؛ گزینه **Allow (اجازه دادن)** را با کنترل انتخاب کنید.

پس از این کار، پوشه‌ای به نام `~/storage` ایجاد می‌شود که شامل میانبرهای زیر است:
- `~/storage/shared` (همان `/sdcard` حافظه داخلی)
- `~/storage/movies` (پوشه فیلم‌ها)
- `~/storage/music` (پوشه آهنگ‌ها)
- `~/storage/downloads` (پوشه دانلودها)
- `~/storage/external-1` (فلش مموری یا هارد USB)

---

## ۷. اتصال USB

فلش مموری یا هارد اکسترنال خود را به پورت USB تلویزیون متصل کنید. اطمینان حاصل کنید که فرمت درایو **FAT32**، **exFAT** یا **NTFS** (سازگار با درایور اندروید تلویزیون) باشد.

---

## ۸. پیدا کردن مسیر USB

در سیستم‌عامل اندروید، حافظه‌های جانبی در یکی از مسیرهای زیر سوار (Mount) می‌شوند:

1. **مسیر مستقیم اندروید:**
   ```bash
   ls -la /storage/
   ```
   نام‌هایی با الگوی ۴ رقم-۴ رقم مانند `/storage/1A2B-3C4D` یا `/storage/ABCD-1234` مشاهده خواهید کرد.
2. **میانبر ساخته‌شده توسط ترموکس:**
   ```bash
   ls -la ~/storage/
   ```
   اگر در خروجی `external-1` دیدید، مسیر شما `~/storage/external-1` است.

## ۹. تنظیم config.json

فایل `config.json` در ریشه پروژه قرار دارد. ساختار آن به شکل زیر است:

```json
{
  "server_name": "Android TV Media Server",
  "port": 8080,
  "host": "0.0.0.0",
  "authentication": false,
  "username": "admin",
  "password": "1234password",
  "show_hidden_files": false,
  "chunk_size_kb": 1024,
  "theme": "dark",
  "storages": [
    {
      "name": "Internal Storage",
      "path": "/sdcard"
    },
    {
      "name": "Movies Folder",
      "path": "/sdcard/Movies"
    },
    {
      "name": "USB Flash Drive",
      "path": "~/storage/external-1"
    },
    {
      "name": "External HDD",
      "path": "/storage/1A2B-3C4D"
    }
  ]
}
```

می‌توانید مسیر فلش خود را به لیست `storages` اضافه کنید. همچنین از طریق صفحه **تنظیمات (Settings)** در مرورگر می‌توانید بدون دست زدن به این فایل، حافظه جدید اضافه کنید!

## ۱۰. اجرای Server

### روش اول: اجرای خودکار با اسکریپت آماده
```bash
chmod +x scripts/*.sh
./scripts/start.sh
```

### روش دوم: اجرا در پس‌زمینه (Background)
برای اینکه با بستن محیط متنی ترموکس سرور خاموش نشود:
```bash
./scripts/start.sh --bg
```

### روش سوم: اجرای مستقیم پایتون
```bash
python3 app.py
```

پس از اجرا، بنری نمایش داده می‌شود که آدرس IP تلویزیون و پورت را نشان می‌دهد:
```text
● Local IP:    192.168.1.100
● Port:        8080
● Web UI:      http://192.168.1.100:8080/
```

## ۱۱. پیدا کردن IP تلویزیون

سرور در زمان اجرا به طور خودکار آی‌پی محلی تلویزیون را تشخیص می‌دهد و چاپ می‌کند.
همچنین در تنظیمات شبکه تلویزیون (Settings -> Network & Internet -> Status) می‌توانید IP تلویزیون خود (مثلاً `192.168.1.105`) را مشاهده فرمایید.

---

## ۱۲. اتصال گوشی به همان Wi-Fi

گوشی موبایل یا تبلت خود را به **همان وای‌فای یا شبکه‌ای** متصل کنید که تلویزیون به آن وصل است.
*(نکته: در صورتی که در روتر گزینه "AP Isolation" فعال باشد، دستگاه‌ها امکان دیدن یکدیگر را نخواهند داشت؛ آن را در تنظیمات مودم خاموش کنید).*

## ۱۳. باز کردن Web UI

در مرورگر گوشی (Chrome, Firefox, Safari و ...)، آدرس آی‌پی تلویزیون همراه با پورت را وارد کنید:
```
http://192.168.1.100:8080
```
صفحه اصلی سرور با طراحی واکنش‌گرا و مدرن بارگذاری می‌شود.

## ۱۴. باز کردن فایل در VLC

۱. وارد پوشه یا حافظه مورد نظر شوید.
۲. در کنار هر فایل ویدیویی یا صوتی روی دکمه **«▶ پخش در VLC»** کلیک کنید.
۳. در پنجره باز شده دو گزینه وجود دارد:
   - **کلیک روی «باز کردن در اپلیکیشن VLC»:** مستقیماً لینک با پروتکل `vlc://` فراخوانی می‌شود.
   - **کپی آدرس لینک:** می‌توانید دکمه کپی را بزنید، وارد برنامه VLC گوشی شوید، به تب **More (بیشتر)** و سپس بخش **New stream (جریان جدید)** بروید و آدرس را پیست کنید و Play را بزنید.

## ۱۵. استفاده از QR Code

با توجه به اینکه تایپ آدرس‌های طولانی روی گوشی ممکن است زمان‌بر باشد:
- در صفحه اصلی یک QR Code برای باز کردن کل سرور وجود دارد (دوربین گوشی را سمت تلویزیون بگیرید).
- در کنار هر فایل نیز یک دکمه **📱 QR** تعبیه شده که بارکد اختصاصی آن فایل ویدیویی را نمایش می‌دهد؛ با اسکن آن توسط دوربین یا VLC فوراً پخش آغاز می‌شود!

## ۱۶. فعال کردن Password

برای جلوگیری از دسترسی مهمانان یا افراد دیگر شبکه خانگی:
۱. به صفحه **تنظیمات (⚙️)** بروید.
۲. گزینه **فعال‌سازی رمز عبور** را روشن کنید.
۳. نام کاربری و رمز دلخواه را وارد کرده و ذخیره نمایید.
۴. سرور از نشست‌های امن (Session) و HTTP Basic Auth برای اپلیکیشن VLC پشتیبانی می‌کند.

---

## ۱۷. رفع مشکلات USB

اگر درایو USB در لیست نمایش داده نشد یا خطای عدم دسترسی داد:
۱. در صفحه اصلی دکمه **«🔄 بروزرسانی حافظه‌ها و USB»** را بزنید تا درایوهای جدید را دوباره اسکن کند.
۲. برخی نسخه‌های اندروید تی‌وی نام فلش را با شناسه عددی ذخیره می‌کنند. دستور زیر را در ترموکس بزنید تا پوشه‌های موجود را ببینید:
   ```bash
   ls /storage/
   ```
   سپس از طریق صفحه تنظیمات سرور، مسیر شناسایی‌شده (مثلاً `/storage/9C33-6BBD`) را اضافه کنید.
۳. مطمئن شوید فلش مموری با فرمت سازگار با اندروید (exFAT یا FAT32) فرمت شده باشد.

---

## ۱۸. رفع مشکل Permission

اگر با خطای `Permission Denied` مواجه شدید:
۱. دوباره دستور `termux-setup-storage` را اجرا کنید و پیام روی صفحه را تایید کنید.
۲. در تنظیمات اندروید تلویزیون به مسیر زیر بروید:
   **Settings -> Apps -> Termux -> Permissions -> Storage** و دسترسی را روی **"Allow all the time"** یا **"مجاز بودن همیشه"** قرار دهید.

---

## ۱۹. رفع مشکل VLC

- **مشکل سیاه شدن صفحه در فایل‌های MKV سنگین:** در تنظیمات VLC گوشی به بخش **Hardware Acceleration** رفته و آن را روی **Full** قرار دهید.
- **عدم کارکرد دکمه باز کردن خودکار در مرورگر:** مرورگرهای کروم گاهی اوقات پروتکل `vlc://` را مسدود می‌کنند؛ از دکمه **«📋 کپی لینک»** استفاده کنید و لینک را مستقیماً در منوی Stream داخل VLC وارد نمایید.

---

## ۲۰. اجرای خودکار Server هنگام روشن شدن تلویزیون

برای راه‌اندازی اتوماتیک سرور با بالا آمدن اندروید تی‌وی:
۱. پکیج **Termux:Boot** را نصب کنید.
۲. دستورات زیر را در ترموکس اجرا کنید:
   ```bash
   mkdir -p ~/.termux/boot
   echo '#!/data/data/com.termux/files/usr/bin/bash' > ~/.termux/boot/start-media-server.sh
   echo 'cd ~/media_server && ./scripts/start.sh --bg' >> ~/.termux/boot/start-media-server.sh
   chmod +x ~/.termux/boot/start-media-server.sh
   ```
اکنون با هر بار روشن شدن تلویزیون، سرور بدون نیاز به دخالت دست در پس‌زمینه آماده کار خواهد بود!

## ۲۱. Stop و Restart کردن Server

- **توقف سرور:**
  ```bash
  ./scripts/stop.sh
  ```
- **راه‌اندازی مجدد (Restart):**
  ```bash
  ./scripts/stop.sh && ./scripts/start.sh --bg
  ```
- **مشاهده لاگ‌های زنده سرور:**
  ```bash
  tail -f logs/server.log
  ```
